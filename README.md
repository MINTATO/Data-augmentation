# Multi-Axis Quality Evaluation of Data Augmentation for Perovskite Solar Cell Datasets

This repository contains the code and Jupyter notebooks associated with the manuscript:

**"Multi-Axis Quality Evaluation of Data Augmentation for Perovskite Solar Cell Datasets"**

accepted for publication in *Digital Discovery*.

## Overview

This repository provides the code used to evaluate data augmentation methods for perovskite solar cell datasets. The analysis evaluates augmentation quality across multiple complementary dimensions and includes the notebooks used to generate the results reported in the manuscript.

## Repository Contents

The repository contains Jupyter notebooks for the data augmentation and evaluation procedures described in the manuscript.

Dependencies required to run the notebooks are listed in `requirements.txt` and can be installed using:

    pip install -r requirements.txt

## Data Availability

The experimental dataset used in this study was collected from Hanyang University, Ajou University, and Chung-Ang University.

The underlying dataset is subject to third-party sharing restrictions and therefore is not publicly distributed through this repository. Access to the data may be requested from the corresponding author, subject to the applicable data-sharing restrictions.
